# Passport

**Languages you live in, not languages you study.**

Passport is a language-learning game built on one idea: you learn a language by *living in it*, not by drilling flashcards. You're dropped into an open-world town — Pokémon Silver's structure with modern graphics, GTA's free-roam-plus-missions feel — where every character is a live LLM agent with a name, a job, a schedule, and a memory of every conversation you've ever had with them.

Nobody there speaks English. You talk to them **out loud**, with your actual voice. They answer at your level and level up as you do. Missions come from the people, not a menu: deliver bread for Rosa, talk your way out of trouble with Doña Carmen, survive the town hall. A bilingual coach — the one person who speaks your language — debriefs you afterward.

## Campaigns

Like Age of Empires, the game is a set of campaigns. Each one is a country, a language, and a town you have to make a life in. Finish one and you get the stamp.

| Campaign | Country | Language | Status |
| --- | --- | --- | --- |
| **Pueblo** | Spain | Spanish | In design |
| *Borgo* | Italy | Italian | Planned |
| *Machi* | Japan | Japanese | Planned |
| *Colonia* | Mexico | Latin-American Spanish | Planned |

Every system — world, residents, missions, coach — is built country-agnostic so a new campaign is content, not a rewrite.
